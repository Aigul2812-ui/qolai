# QolAI

QolAI — доска задач по поиску и заказу исполнителей в **Алматинской области**.
Одностраничное веб-приложение (один HTML-файл, без сервера), три языка:
**Қаз / Рус / Eng** (переключатель в правом верхнем углу, выбор сохраняется в браузере).

## Возможности

- **Заказчик** — размещает задачу: категория, район области (9 районов), село/посёлок,
  бюджет, способ оплаты. Видит ставки исполнителей и принимает одну.
- **Исполнитель** — выбирает задачу из списка, принимает цену заказчика или
  предлагает свою (ставка).
- **Пятак** — «живой» список исполнителей, отметившихся как доступные прямо сейчас;
  заказчикам можно сразу «Позвать» (форма предзаполняется).
- **Публичная оферта** — кнопка «Оферта» в шапке, комиссия сервиса **5%** от суммы
  оплаты за выполненную задачу (удерживается из оплаты).
- **Демо-карты** — форма привязки карты (Luhn-проверка), хранится только в памяти
  браузера. В реальном приложении — только через PCI DSS-шлюз (Kaspi Pay и т.п.).

## Структура

```
qolai/
  index.html      — всё приложение (стили, разметка, логика, i18n)
  check_i18n.py   — служебная проверка: все ключи t("...") есть в словаре I18N
```

## Локальный запуск

```powershell
python -m http.server 8734
# открыть http://localhost:8734/
```

## Деплой

GitHub Pages, имя сайта: **qolai** (репозиторий `qolai`, ветка `main`,
Pages → Deploy from branch). Ссылка: `https://<username>.github.io/qolai/`.

## Замечания по i18n

- Все строки — в словаре `I18N` (функция `N(ru, kk, en)`).
- Данные демо-задач тоже локализованы (`{ru,kk,en}`-объекты), пользовательский
  ввод — обычные строки.
- Проверка: `python check_i18n.py` («missing» — ложные срабатывания на `set("id")`).
